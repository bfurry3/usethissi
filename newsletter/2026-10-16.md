## The big one
### Meta open-weights Muse Spark Open (Oct 15)
**What happened:** Meta released Muse Spark Open, an open-weight multimodal model with 816B total parameters (42B active) and a 1M-token context window, built for coding and agentic work.
**Why it matters for builders:** You can run a frontier-class coding model via Fireworks, Groq, Together, OpenRouter and others, or pull weights from Hugging Face. It is also the first in its class Meta optimized to run on two Apple M5 Ultra Mac Studios with MLX.
**How to try it:** Start from the [Muse Spark Open collection on Hugging Face](https://huggingface.co/collections/meta-models/muse-spark-open), or hit a hosted endpoint on Fireworks/Groq/Together.
[Read the source](https://research.meta.ai/blog/muse-spark-open)
