First-hour quickstarts

Get a real result in your first session

One setup tip per top pick. Do this first and you'll get something useful before the free trial runs out.

Lovable · Vibe-code an app or landing page

Write a one-paragraph spec (pages, users, data) before your first prompt, and connect GitHub early so you own the code.

Cursor · AI coding assistant

Add a project rules file describing your stack and conventions; it keeps every agent edit on-style.

n8n · Set up or run AI agents

Start from a community template, then swap in your credentials. Self-host with Docker if you want unlimited runs.

Make · Automate workflows

Build the scenario with 'Run once' and sample data first, then turn on scheduling. Watch your credit count.

Scenario · Make game art and sprites

Train a custom model on 10-20 of your own reference images so every asset stays in one consistent style.

Suno · Generate music and SFX

Put genre, tempo and mood in the style box and keep lyrics separate. Free tier is non-commercial, so upgrade before you ship.

Runway · Edit and generate video

Lock a strong still image first, then animate it; image-to-video gives far more control than text alone.

Claude · Write content

Create a Project with your style guide and examples attached so every draft starts with your context.

Perplexity · Research

Use Spaces to save sources and instructions per topic, and always click through to verify key citations.

ElevenLabs · Voice and TTS

Clone your voice from a clean 1-2 minute recording in a quiet room; audio quality matters more than length.
