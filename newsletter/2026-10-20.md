## The big one
### MiniMax M3.1 Flash goes GA (Oct 19)
**What happened:** MiniMax released M3.1 Flash, its new fast model for agentic tasks, coding, computer use and security work. It has a 1M-token context window and costs $0.15 per 1M input tokens, $0.60 per 1M output tokens and $0.015 per 1M cached input tokens.
**Why it matters for builders:** It is one of the cheapest long-context options for agent loops that burn tokens all day. MiniMax says agent task costs are 70% lower than its previous model. You can use it in the MiniMax Code desktop app, through the API, or point Claude Code, Cursor or OpenCode at an M Plan key.
**The catch:** It is hosted only for now. MiniMax says the weights come "later", and every benchmark in the launch post is self-reported. Reasoning is always on, so plan for slower answers on simple asks.
**How to try it:** Call `MiniMax-M3.1-Flash` on the [MiniMax developer platform](https://platform.minimax.io/docs/guides/text-generation), or use the M Plan (Go is $22/mo) inside MiniMax Code.
[Read the source](https://www.minimax.io/blog/minimax-m31f)

## Quick hits
- **Kling 4.0 (Oct 15):** 30-second clips in one pass, up to 15 references and 10 keyframes, stereo audio, plus MCP and CLI access. API access is still "coming soon". [Source](https://ir.kuaishou.com/news-releases/news-release-details/kling-ai-officially-launches-next-generation-kling-40-raising/)
- **Notion Agents (Oct 19):** Agents now get their own computer and browser and can run tasks for up to 24 hours. A new Auto router picks the model, you can connect a ChatGPT Plus, Pro or Go plan, and all AI use moves to a new credit system. [Source](https://www.notion.com/releases/2026-10-19)
- **GitHub Copilot (Oct 19):** GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini, Gemini 3.7 Flash and Grok 4.5 are retired. Suggested swaps are GPT-6.1 Sol, GPT-6 Luna, Gemini 3.8 Flash and Grok 4.7. [Source](https://github.blog/changelog/2026-10-19-github-copilot-models-deprecated-on-october-19-2026/)
- **Mintlify Autopilot (Oct 20):** A beta agent that watches your repos and opens a docs PR when code changes. Each PR costs 250 credits, and runs that find nothing cost nothing. [Source](https://www.mintlify.com/blog/autopilot)

## Tool of the day

**Use it for:** A terminal coding agent on Meta's Muse models, with workers and reviewers running in parallel.
**Price:** $5/mo Everyday Usage (10 to 50 prompts every 5 hours), $15/mo High Usage, $50/mo Power Usage with Muse Wonder Full.

## One tip to try
**Bake off before you switch models:** Pick three real tasks from last week. Run each on your current model and the new one, then compare cost per finished task, not cost per token. A cheap model that needs two retries is not cheap.
